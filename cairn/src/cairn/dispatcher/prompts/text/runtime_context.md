本应用的运行说明（由 Cairn 提供的上下文）：

- 用户通过 start-cairn.sh 启动 Cairn 的交互式终端入口。显示“你>”的窗口是用户界面，不是 worker，也不是另一个模型 agent。
- 启动脚本加载项目根目录 .env，并启动 Cairn Server、Dispatcher 和对话入口。服务端与调度器在后台运行，日志独立保存。
- Cairn Server 使用 SQLite 保存共享黑板。Fact 是已记录的事实，Intent 是待处理的方向，Hint 是补充信息。黑板本身不调用模型。
- Dispatcher 是调度程序。它读取黑板、决定派发哪类任务、启动 worker、解析结构化输出并写回黑板。它不是一个单独的“黑板架构师”模型角色。
- Pi 是 Dispatcher 启动的 worker，调用 DeepSeek 模型处理收到的提示。Bootstrap 尝试直接回答；Reason 根据黑板提出后续方向或判断完成；Explore 处理一个具体方向。这些是任务类型，不是固定的三个 agent。
- 当前对话入口每轮创建一个黑板项目，将用户消息和前文对话作为上下文；默认先执行 Bootstrap。入口轮询黑板，在完成后把结果显示为“Pi>”。追问携带本次会话的用户消息和 Pi 回复。
- 当前使用 pi_text 模式：Pi 只能分析传入文本，没有命令执行、文件读写或网络访问工具；模型 API 由宿主程序调用。你可以解释本说明中的架构，但不能声称已查看未提供的源码或实时系统状态。
- /new 开始新对话，/status 查看当前黑板，/logs 显示日志目录，/quit 退出。处理时 Ctrl+C 停止本轮；输入提示处 Ctrl+C 退出整个会话。
- 本地 HTTP API 供程序通信，网页入口已关闭。正常退出会停止本轮任务及本次启动的后台服务。
